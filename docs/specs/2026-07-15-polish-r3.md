# Polish Touchups — Round 3

**From:** Executive Studio Coordinator
**To:** Senior Codesmith (Sol)
**Branch:** `codex/v1.2-qol`

Four items. Two are CSS, one is a config change, one is a mechanism choice.

---

## 1. Minimum window size

The app opens with `minWidth: 960, minHeight: 560`. Buttons wrap and layouts break at small sizes. Raise the minimum to `1280 × 720` so the layout always has room to breathe. Nobody watches movies in a tiny window.

## 2. Beveled edges on wood surfaces

The wood panels currently have flat edges. Give them the look of router woodwork — slightly rounded corners (`border-radius`) and beveled edges via inset `box-shadow` (a light highlight on top, a dark shadow on bottom). The reference is real furniture: a routed edge catches light on the top and casts shadow on the bottom. Subtle, not exaggerated. The wood should feel like it has physical depth.

## 3. Earbud play/pause — media key support

The Creative Director taps his earbud to play/pause in browsers and VLC. That's a system media key event. Wire up play/pause to the OS media key so earbud taps control WatchAlong playback.

Choose the mechanism: `globalShortcut` (works system-wide, even when the app isn't focused — probably what the user wants, since they're watching a movie with the app behind the player) or focused-only media key listening. Either is viable; pick the one that feels right and name it in the commit.

## 4. Font and title treatment

The library titles currently use `Georgia, "Times New Roman", serif`. That reads as "newspaper website," not "engraved signage on a media cabinet." Switch the title/heading font to a clean sans-serif — the system stack the body already uses (`"Segoe UI", ui-sans-serif, system-ui, ...`) or a deliberate choice if you have a better one. Sans-serif titles will read as more modern and more "hardware front panel" than serif.

Second experiment, separate from the font swap: try a chiseled-into-wood effect on titles using CSS `text-shadow` — a dark shadow below and a warm highlight above, simulating engraving. This is the kind of effect that either looks beautiful or looks like a Photoshop tutorial. Try it. If it works, keep it. If it looks cheap, drop it. Don't force it.
